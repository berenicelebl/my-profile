---
description: Generate a detailed implementation plan for a feature or task
---

Create a comprehensive implementation workflow for the requested feature or task.

The workflow will include:

1. **Requirements Analysis**:
   - Feature/task description and goals
   - User stories or use cases
   - Success criteria

2. **Technical Planning**:
   - Files to create/modify
   - Dependencies needed
   - Database/API changes (if applicable)
   - Breaking changes or migration needs

3. **Implementation Steps**:
   Detailed step-by-step breakdown:
   - Setup and configuration
   - Core functionality implementation
   - UI/UX components
   - Testing requirements
   - Documentation needs

4. **Risk Assessment**:
   - Potential blockers
   - Complex areas requiring extra attention
   - Backwards compatibility concerns

5. **Testing Strategy**:
   - Unit tests to write
   - Integration scenarios
   - Manual testing checklist

6. **Rollout Plan**:
   - Deployment steps
   - Monitoring requirements
   - Rollback procedure

After presenting the plan, I'll ask if you'd like to proceed with implementation or adjust the approach.
