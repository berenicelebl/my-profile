description: Run diagnostic checks on code for common issues and errors
---

Analyze the codebase and perform comprehensive diagnostic checks:

1. **HTML/CSS Validation**: Check for syntax errors, invalid attributes, malformed tags
2. **JavaScript Issues**: Look for console errors, undefined variables, syntax problems
3. **Code Quality**: Identify duplicate declarations, unused code, invalid selectors
4. **Best Practices**: Flag security issues, accessibility problems, performance bottlenecks
5. **File Structure**: Verify correct file paths, missing dependencies, broken links

Provide a clear diagnostic report with:
- Critical issues (must fix)
- Warnings (should fix)
- Suggestions (nice to have)
- Line numbers for each issue

After reporting, ask if the user wants me to fix the issues automatically.
